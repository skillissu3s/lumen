Only what a day needs

Tasks

Type “Call Sam tomorrow 3pm !high” and it’s understood. Lists, sections, subtasks, repeats and a board.

Calendar

Time-block on a timeline, drag tasks onto your day, and shape every view to how you plan.

Docs

Markdown documents beside your tasks, with a quiet editor and a live preview.

Chat

Channels and direct messages with the people you invite. Only the admin can invite.

Plugins

Add a focus timer, a usage monitor, or your own. Each one runs sandboxed with the permissions you grant.

Your data, in Git

Every list, event and doc is a text file you can read, diff, back up and take with you.

Run it the way you like

With GitHub

No server at all. The web app reads and writes a repository you choose.
