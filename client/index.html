Everything in one calm place

Boards

Columns of cards with labels, checklists, covers and due dates. Type “Call Sam tomorrow 3pm !high” and it’s understood.

Calendar

Plan by day, week or month, or on a timeline. Drag cards onto your day to give them a time.

Idea boards

An open canvas for notes, groups and the arrows between them. When an idea is ready, make it a card.

Docs

Markdown documents beside your boards, with a quiet editor and a live preview.

Chat

Channels and direct messages with the people you invite. Only the admin can invite.

Plugins

Add a focus timer, a usage monitor, or your own. Each one runs sandboxed with the permissions you grant.

Run it the way you like

It’s just text

A board is a markdown file: each heading is a column and each line a card — the same format as Obsidian’s Kanban plugin — so it reads fine anywhere, merges cleanly in git, and outlives any app.
