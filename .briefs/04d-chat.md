# Brief 04d — Chat (server mode)

Read `AGENTS.md`, `docs/API.md` (chat endpoints and WebSocket messages — implement against them exactly), `docs/STORAGE.md` (chat), and the client code you use — real exports only: `client/src/lib/{api,socket,router}.js`, `client/src/store/{session,ui}.js`, `client/src/components/ui/`. Create ONLY `client/src/views/chat/**` (+ `chat.css`) and replace the stub `client/src/views/ChatView.jsx` (default export, props `{ route }`; routes `/chat` and `/chat/<channel>`). Libraries: `markdown-it`, `dompurify`.

Chat exists only in server mode (people the admin invited). In GitHub/desktop mode render an `EmptyState`: "Chat needs a Lumen server — it's for talking with people you invite."

- **Channel list** (left, 240 px; drawer under 760 px): Channels (`# general`, …) and Direct messages (avatar + name), unread counts (bold + badge), "+" to create a channel (name, members: everyone / chosen people from `GET /api/users`) and "+" to start a DM (pick a person). Presence dot on DMs from socket `presence`.
- **Messages**: newest at the bottom; load 100, "load earlier" on scroll to top (`before`); grouped by author when consecutive within 5 min (avatar + name + time on the first); day separators; markdown-lite rendering (markdown-it with `html: false`, `linkify`, `breaks: true`, only inline + lists + code; sanitized with DOMPurify); `@handle` mentions highlighted (your own mention more strongly); edited label; deleted messages show "Message deleted" in italics. Hover actions on own messages: Edit (inline, Enter saves / Esc cancels), Delete (confirm); on any: Reply (shows a quoted snippet above the composer and on the message), Copy text.
- **Composer**: textarea auto-grows to 8 lines, Enter sends, Shift+Enter newline, `@` opens a mention picker (filter as you type, arrow keys + Enter), typing indicator sent at most every 3 s (`{ type: 'typing', channel }`) and shown as "Ana is typing…" for 5 s after the last event; Up arrow in an empty composer edits your last message. Optimistic send (pending style until the server answers; on error show "Couldn't send — Retry").
- Realtime: socket `chat` messages append/replace in the open channel and bump unread elsewhere; `channels` → refetch list; mark read (`POST /api/chat/read`) when the channel is open and the window focused, with the latest message's `at`. Update a `useUI` value `chatUnread` (total) so the sidebar badge can show it — add that key to `ui.js` if missing.
- Stick to bottom when already at the bottom; otherwise show a "New messages ↓" pill.
- Accessible: message list is a `role="log"` with `aria-live="polite"` for new messages (not for history loads), composer labelled, all actions keyboard-reachable.

Done when `npx vite build` and `npm test` pass; test the flows against a running server (`npm run dev`, then use the API with two users — admin + an invited member — and verify the UI's network calls/state as far as you can without a screen). Report what you built and what you verified.
